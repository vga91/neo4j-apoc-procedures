Syntax: `[<]RELATIONSHIP_TYPE1[>][prop_filter]|[<]RELATIONSHIP_TYPE2[>][prop_filter]|...`

[opts=header,cols="m,m,a"]
|===
| input | type | direction
| LIKES> | LIKES | OUTGOING
| <FOLLOWS | FOLLOWS  | INCOMING
| KNOWS  | KNOWS | BOTH
| > | any type | OUTGOING
| < | any type | INCOMING
|===

We can also filter relationship-type properties through `prop_filter` part.  See <<prop-filter>>.

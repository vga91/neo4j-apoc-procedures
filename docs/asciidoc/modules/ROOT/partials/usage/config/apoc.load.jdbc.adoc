The procedure support the following config parameters:

.Config parameters
[opts=header]
|===
| ignore | List<String> | [] | which field to ignore
| nullValues | List<String> | [] | which values to treat as null, e.g. `['na',false]`
| arraySep | String |  ';' | array separator of the value, in case `array` is true
| array | boolean |  false | to handle the value as an array
| mapping | Map | {} | per field mapping, entry key is field name, .e.g `{years:{....}` see below
| timezone | String | `db.temporal.timezone` from `neo4j.conf` | default timezone in case of localtime and localdatetime without this one
|===

where `mapping` supports the following values:

.Mapping parameters
[opts=header]
|===
| name | type | default | description
| type | string | type of the conversion requested (`STRING`, `INTEGER`, `FLOAT`, `BOOLEAN`, `NULL`, `LIST`, `DATE`, `DATE_TIME`, `LOCAL_DATE`, `LOCAL_DATE_TIME`, `LOCAL_TIME`, `TIME`, `POINT`)
| dateFormat | <format>` | null | convert the Date into String
| dateParse | [<formats>]` | null | convert the String into Date
| ignore | boolean | true if is included in `ignore` config parameter (see table above), otherwise false | column to ignore  (if true)
| array` | boolean | value of `array` config parameter (see table above) | to handle the value as an array
| arraySep` | String | the value of `arraySep` config parameter (see table above)  | the array separator of the value, in case `array` is true
|===

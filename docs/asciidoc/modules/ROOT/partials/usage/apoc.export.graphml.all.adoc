The `apoc.export.graphml.all` procedure exports the whole database to a GraphML file or as a stream.

The following query exports the whole database to the file `movies.graphml`:
[source,cypher]
----
CALL apoc.export.graphml.all("movies.graphml", {})
----

[source,cypher]
----
CALL apoc.export.graphml.all(null, {stream:true})
YIELD file, nodes, relationships, properties, data
RETURN file, nodes, relationships, properties, data;
----

In case of properties with the same name but multiple data types, will be create a `key` tag for each data type with a different id (by appending an unique id suffix).
So you can execute with the following data set (where `alpha` and `beta` have mixed types):

[source,cypher]
----
CREATE (:MultiType {alpha: 'fooBar', otherProp: 1})-[:MY_REL {beta: 'baz', otherPropRel: 1}]->(:Another),
(:MultiType {alpha: 11, otherProp: 2})-[:MY_REL {beta: 123, otherPropRel: 2}]->(:Another),
(:MultiType {alpha: [11, 22], otherProp: 3})-[:MY_REL {beta: [123, 456], otherPropRel: 3}]->(:Another)
----
Combined with the following query:
[source,cypher]
----
CALL apoc.export.graphml.all(".graphMultiType.graphml", {useTypes: true, readLabels: true})
----

You can also use the configuration `sampling` (default: `false`).
With this config, the `apoc.export.graphml.all` procedure uses
the `apoc.meta.nodeTypeProperties` and the `apoc.meta.relTypeProperties` procedures under the hood to get the property types.
You can customize the configuration of these 2 `apoc.meta.*` procedure, using the `samplingConfig: MAP` configuration,
to limit the number of nodes/rels to analyze.
So you can execute with the following data set:
[source,cypher]
----
CREATE (:MultiType {alpha: 'fooBar', otherProp: 1})-[:MY_REL {beta: 'baz', otherPropRel: 1}]->(:Another),
(:MultiType {alpha: 11, otherProp: 2})-[:MY_REL {beta: 123, otherPropRel: 2}]->(:Another),
(:MultiType {alpha: [11, 22], otherProp: 3})-[:MY_REL {beta: [123, 456], otherPropRel: 3}]->(:Another)
----
Combined with the following query:
[source,cypher]
----
CALL apoc.export.graphml.all(".graphMultiType.graphml", {useTypes: true, readLabels: true, sampling: true, samplingConfig: {sample: 1}})
----

Execution of the above query would output content similar to that below (result could change depending on the `sample`):

[[systemdb]]
= SystemDB
:description: This section describes procedures that can be used to access the contents of Neo4j system db.

In Neo4j 4.0 the concept of multi-database was introduced. There's now a database called `system` which contains some
internal information, e.g. configured permissions. Those can be exposed by APOC.

image::apoc.systemdb.graph.png[scaledwidth="100%"]

[CAUTION]
====
Do not rely on the data structures within `system` database. They are a non-public implementation details of Neo4j
and might change within minor release updates.
====

.isType example
[source,cypher]
----
CALL apoc.systemdb.graph() YIELD nodes, relationships RETURN *;
CALL apoc.systemdb.execute('SHOW DATABASES') YIELD row RETURN row.name as dbName;
CALL apoc.systemdb.execute(["CREATE USER foo", "GRANT ROLE myRole TO foo"])
----

To create a new node (:Sys:Node {alpha: 'beta'}), we can execute:

[source, cypher]
----
call apoc.systemdb.create.node(["Sys", "Node"], {alpha: 'beta'})
----

.Results
[opts="header",cols="1"]
|===
| node
| {"identity": 21, "labels": ["Sys", "Node"], "properties": {"alpha": "beta" } }
|===

To execute a procedure equivalent to `MERGE (node:Sys:Node {alpha: 'beta'}) ON CREATE SET node.gamma='delta`, 
we can execute:

[source, cypher]
----
CALL apoc.systemdb.merge.node(['Sys', 'Node'], {alpha: 'beta'}, {gamma: 'delta'})
----

.Results
[opts="header",cols="1"]
|===
| node
| {"identity": 21, "labels": ["Sys", "Node"], "properties": {"alpha": "beta" } }
|===


In the previous case, we create nothing becuase an equivalent node exist.
Otherwise, executing with this query we receive a new node:

[source, cypher]
----
CALL apoc.systemdb.merge.node(['Sys', 'Node'], {alpha: 'anotherOne'}, {gamma: 'delta'})
----

.Results
[opts="header",cols="1"]
|===
| node
| {"identity": 21, "labels": ["Sys", "Node"], "properties": {"alpha": "anotherOne", "gamma": "delta"} }
|===

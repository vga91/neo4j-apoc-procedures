== Multi database support for apoc developers

Notes about multi database support for apoc developers.

=== What is re-initialized

In a cluster LEADER:

* TTLConfigExtensionFactory
** TTLConfig
* CoreApocGlobalComponents
** CypherInitializer
** TriggerHandler
* ExtendedApocGlobalComponents
** TTLLifeCycle
** UuidHandler
** LoadDirectoryHandler
** CypherProceduresHandler
* JdbcRegistererInitFactory
* ApocConfigExtensionFactory
* ApocExtensionFactory
** ApocLifecycle
* PoolExtensionFactory
** Pools
* RegisterComponentFactory
* RegisterComponentLifecycle

In a cluster FOLLOWER / single instance db :

* TTLConfigExtensionFactory
** TTLConfig
* ApocExtensionFactory
** ApocLifecycle
* CoreApocGlobalComponents
** CypherInitializer
** TriggerHandler
* ExtendedApocGlobalComponents
** TTLLifeCycle
** UuidHandler
** LoadDirectoryHandler
** CypherProceduresHandler


=== What did we do in apoc to accommodate for multi-db so far

* UuidHandler: to support multi-db we have a per db DatabaseManagementService.registerTransactionEventListener(dbName, this)
* TriggerHandler: to support multi-db we create for each a system node with a property `database` 
* apoc.ttl.*: to support multi-db we have a `TTLConfig.Values` specific per db
* Cypher initializer: `CypherProceduresHandler.storeFunction()` and `CypherProceduresHandler.storeProcedure()` specific per db
